# ResearchHub — Research Project Collaboration Portal

A browser-based project collaboration prototype built using **HTML5, CSS3 and Vanilla JavaScript only**. No frameworks or backend are used.

## Run the website
1. Download and extract the ZIP.
2. Open `index.html` in Chrome, Edge, Firefox or another modern browser.
3. The dashboard opens with sample project, task, milestone, resource and team data.
4. Use the left navigation to explore each module.

## Implemented modules
- Overview dashboard with project, task and team statistics
- Project creation, progress editing, search and deletion
- Kanban-style task board with status updates and priorities
- Milestone creation and completion tracking
- Research resource links, notes, search and deletion
- Team member management with roles
- Activity history
- Responsive layout for desktop, tablet and mobile
- LocalStorage persistence

## Technology
- HTML5
- CSS3
- Vanilla JavaScript
- Browser LocalStorage

## Important limitations
This is a frontend-only academic prototype. Data is saved in the current browser using LocalStorage. It does not synchronize across devices or provide real multi-user accounts, secure authentication, server-side role enforcement, or cloud file uploads. Resource links can be saved; file upload storage is not included because there is no backend.

For a real multi-user deployment, a backend and database would be required.
